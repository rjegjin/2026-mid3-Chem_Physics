# 🧪 중3 과학 인터랙티브 수업 자료

중학교 3학년 과학 수업을 위한 인터랙티브 HTML 강의 자료 모음입니다. 화학 반응의 규칙 단원과 물리 단원(물체의 운동, 일과 에너지, 역학적 에너지)을 프레젠테이션형 슬라이드로 제공합니다.

## 🌟 주요 특징

- **인터랙티브 슬라이드:** 클릭 및 키보드 조작을 통한 순차적 정보 공개
- **수업 흐름 중심 설계:** 도입 질문, 핵심 개념, 예시, 형성평가를 차시별로 구성
- **시각 자료와 그래프:** SVG 이미지, Chart.js 그래프, 카드형 개념 정리 활용
- **수식 지원:** MathJax 및 HTML 수식 표기를 활용한 과학 공식 제시
- **퀴즈 피드백 제어:** 학생이 답하기 전에는 피드백을 숨기고, 응답 후 확인하도록 설계
- **반응형 디자인:** PC, 태블릿, 모바일 기기에서 활용 가능
- **품질 점검 자동화:** HTML 링크, 슬라이드 번호, 렌더링, 레이아웃 이상을 검사하는 체크 루틴 제공

## ✅ 품질 점검 루틴

HTML 슬라이드 수정 후에는 아래 순서로 점검합니다.

```bash
make check
```

물리 파트만 빠르게 다시 보고 싶다면:

```bash
make check-phys
```

실제 렌더링까지 자동으로 보려면:

```bash
make render-check FILE=8_uniform_motion.html
```

이 명령은 다음을 자동 수행합니다.

- 임시 로컬 서버 기동
- Chromium 헤드리스 렌더링
- 데스크톱/모바일 스크린샷 저장
- `?view=all` 전체 문서 스크린샷 저장
- DOM 기준 이미지 깨짐, 가로 오버플로, 레이아웃 이상 징후를 JSON으로 기록

결과물은 `tmp_checks/` 아래에 저장됩니다.

커밋 전에 자동으로 막히게 하려면 한 번만 실행합니다.

```bash
make install-hooks
```

이후 `git commit` 시 `check_html_quality.py`가 자동 실행되어 다음 항목을 검사합니다.

- 깨진 로컬/원격 `src`, `href`
- 슬라이드 `data-slide-num`, `data-title`
- 수식 표기 토큰 누락 및 자주 나는 오기 패턴
- 닫히지 않은 `sub`, `sup` 태그
- 물리 퀴즈 피드백 표시 방식
- 화면 너비 초과 및 렌더링 이상 징후
