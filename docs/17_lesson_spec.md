# 17강 Lesson Spec — VI단원 종합: 에너지는 모습을 바꾼다

## PASS 1 — Lesson Spec

| 항목 | 내용 |
|---|---|
| 위치 | 물리 VI-4 (단원 마무리). 14·15·16강을 종합한다 |
| 성취기준 | 새로 도입하지 않는다. [9과22-01][9과22-02][9과22-03]을 회수한다 |
| 소요 | 45분 |
| 선수 | 14강 역학적 에너지 보존 · 15강 전자기 유도 · 16강 소비 전력 |
| 핵심 질문 | 댐에 고인 물 한 통이 내 방 전등을 켜기까지, 에너지는 몇 번 모습을 바꾸는가? |
| 도착점 | 학생이 에너지 전환 사슬을 **끊김 없이** 말하고, 각 단계에서 무엇이 새는지 설명한다 |

**이 차시가 하지 않는 것**: 새 개념 도입, 효율의 정량 계산.
전환 사슬을 잇는 것과 오개념 교정에 집중한다.

## PASS 2 — Concept Architecture

### 하나의 사슬

```
위치 에너지 → 운동 에너지 → [발전기·전자기 유도] → 전기 에너지 → 빛·열·운동·소리
   └─ 14강 ─────────────┘   └─ 15강 ──────────┘   └─ 16강 ──────────────┘
```

세 차시가 각각 사슬의 한 마디였다는 것이 이 차시의 핵심 통찰이다.

### 각 마디에서 새는 것

| 마디 | 담당 차시 | 새는 형태 |
|---|---|---|
| 위치 → 운동 | 14강 | 공기 저항, 마찰 → 열 |
| 운동 → 전기 | 15강 | 코일 저항, 축 마찰 → 열·소리 |
| 전기 → 목적 | 16강 | 목적 외 전환 → 열 (백열전구가 대표) |

**새지만 사라지지 않는다.** 전체 에너지는 보존된다 — 이것이 회수할 문장이다.

### 교정할 오개념 3종

1. "에너지가 소모되어 없어진다" → 형태가 바뀌고 주변으로 분산된다
2. "발전기가 전기를 만들어낸다" → 무에서 만들지 않는다. 역학적 에너지를 전환한다
3. "소비 전력이 크면 언제나 전기를 많이 쓴다" → 전력 × 시간

### 과학사

- 줄(James Joule, 1843) — 물을 젓는 일이 물을 데운다는 것을 측정해
  역학적 에너지와 열이 같은 것임을 보였다. 사슬의 '새는 부분'이 열이라는 근거.
- 패러데이(1831) — 15강 회수.
- 에디슨과 백열전구 — 16강 회수. 에너지의 95%가 열로 갔다.

## PASS 3 — Section Map (아키타입 나열)

```
1  cover          댐의 물 한 통 → 전등
2  hook           사슬 전체 SVG를 한 번에 보여준다
3  predict        세 지점에서 무엇이 새는지 예상
4  objectives     세 차시를 하나로 꿰기
5  concept        전환 사슬 — 각 마디와 담당 차시
6  observe        마디별 새는 형태 표
7  rule           빈칸으로 사슬 완성 (.rule-blank)
8  compare        백열전구 vs LED — 같은 밝기, 다른 손실
9  apply          내 방 전등에서 발전소까지 거꾸로 추적
10 summary        회수: 전환 · 보존 · 전력×시간
11 quiz           형성평가
12 misconception  "에너지가 소모된다" 반례 + 출구 질문
```

12장. `explore`는 넣지 않는다 — 애플릿은 15·16강에 이미 있고,
복습 차시에 새 시뮬레이션을 만드는 것은 이 차시의 목적이 아니다.
