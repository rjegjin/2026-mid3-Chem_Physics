Lecture 08: $\sigma$ Frameworks, $\pi$ Donors and Acceptors

Outline only — 본문 미작성

0. Scope

Central question

metal–ligand bonding을 MO 관점에서 어떻게 설명하는가?

Requires

Module 06 — ligand SALC와 $\Gamma_\sigma = A_{1g}+E_g+T_{1u}$ · Module 07 — $t_{2g}/e_g$ 라벨

Feeds

Module 09 — $\Delta_o$와 Racah $B$ · Module 11 — CO의 back-bonding

이 모듈의 목적. CFT가 맞힌 갈라짐을 MO로 다시 유도하되, CFT가 틀린 부분 — 분광화학적 계열의 순서 — 를 설명해 낸다.

1. The $\sigma$-Only Framework

$$ \Gamma_\sigma = A_{1g} + E_g + T_{1u} $$
  • 6개 리간드 lone pair 벡터를 기저로 — Module 06에서 이미 유도했다
  • 금속 $s \to A_{1g}$, $p \to T_{1u}$, $d_{z^2}, d_{x^2-y^2} \to E_g$
  • $d_{xy}, d_{yz}, d_{zx} \to T_{2g}$ — 짝이 없다. $\sigma$만 있으면 완전 비결합
  • $\Delta_o$의 정체 — 비결합 $t_{2g}$와 반결합 $e_g^*$ 사이의 간격

2. $\pi$ Donor Ligands

  • 채워진 리간드 $\pi$ 궤도가 $T_{2g}$ 대칭 조합을 만든다
  • 금속 $t_{2g}$와 상호작용 — $t_{2g}$가 반결합이 되어 올라간다
  • $e_g^*$는 그대로 ⇒ $\Delta_o$ 감소
  • 예: $\mathrm{I^-} < \mathrm{Br^-} < \mathrm{Cl^-} < \mathrm{F^-}$ — 약한 장 끝
  • 할라이드 착물이 흔히 high spin인 이유

3. $\pi$ Acceptor Ligands

  • 빈 리간드 $\pi^*$가 $T_{2g}$ 대칭 조합을 만든다
  • 금속 $d_\pi \to \pi^*$ back-donation ⇒ $t_{2g}$가 결합성이 되어 내려간다
  • ⇒ $\Delta_o$ 증가
  • 예: $\mathrm{CN^-}$, $\mathrm{CO}$ — 강한 장 끝
  • $\mathrm{CO}$ 신축 진동수 감소가 back-donation의 직접 증거

4. Reading the Spectrochemical Series

$$ \mathrm{I^- < Br^- < Cl^- < F^- < H_2O < NH_3 < en < NO_2^- < CN^- < CO} $$
  • 왼쪽 끝 — $\pi$ donor. $\Delta_o$를 깎는다
  • 가운데 — $\sigma$ donor만. $\mathrm{NH_3}$에는 $\pi$ 궤도가 없다
  • 오른쪽 끝 — $\pi$ acceptor. $\Delta_o$를 키운다
  • $\mathrm{H_2O}$가 $\mathrm{NH_3}$보다 약한 이유 — 산소의 lone pair가 $\pi$ donor로 작동한다
  • 순서를 외우지 않는다. 세 부류로 나누면 순서가 나온다

5. Beyond the Series

  • Nephelauxetic effect — 착물에서 전자 반발이 줄어든다(공유성의 척도)
  • Racah 파라미터 $B$의 감소 — Module 09에서 정량화한다
  • 18전자 규칙의 뿌리 — $t_{2g}$ 6개 + 결합성 6쌍
  • $\mathrm{SF_6}$의 $\Gamma_\sigma$와 같은 식이라는 점(Module 06 §9)

6. Key Competencies

  • $O_h$ MO 도표를 $\sigma$만, $\pi$ donor, $\pi$ acceptor 세 경우로 그린다
  • 임의의 리간드를 세 부류 중 하나로 분류하고 $\Delta_o$ 영향을 예측한다
  • $\Delta_o$가 CFT에서와 LFT에서 각각 무엇의 간격인지 구별해 말한다
  • CFT가 설명 못 한 계열 순서를 LFT로 설명한다
